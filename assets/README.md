# Map background

`ne_50m_land.geojson` is Natural Earth's 1:50 million land dataset, downloaded
from the project's repository on 2026-10-25:

https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_50m_land.geojson

Natural Earth map data are public domain:
https://www.naturalearthdata.com/about/terms-of-use/

The local copy allows `ground_track.py` to draw the background without network
access or additional mapping packages.
